# RISE

This repository contains the experimental stimuli and supporting media files for the **Remote Infant Studies of Early Learning (RISE)** battery. The RISE battery is currently being administered online at [Children Helping Science (CHS)](https://childrenhelpingscience.com/).

`RISE` = Remote Infant Studies of Early Learning.

The RISE battery was developed to investigate early cognitive, social, and language development using a standardized set of remotely administered infant tasks. Each task is in video parts in this repo. 

## Repo structure

The main `rise/` folder contains experimental stimuli organized by media format and task. This organization follows the CHS recommended structure. Therefore, for ease, we have also included a section for each task.

```text
.
├── img/                    # Imags used for all RISE tasks
├── mp3/                    # Audio stimuli in MP3 format
├── mp4/                    # Video stimuli in MP4 format
├── ogg/                    # Audio stimuli in OGG format
├── videos_by_task/         # Video stimuli organized by experimental task
└── webm/                   # Video stimuli in WebM format
```

## RISE battery

These are the seven tasks included in the RISE Battery:

1. **Geo-Social Attention:** Assessing infants' preference for social versus nonsocial stimuli by comparing looking time to videos of dancing children and moving geometric shapes.
2. **Visual Paired Comparison:** Looking at visual recognition memory through infants' preference for novel versus familiar social (Faces) and nonsocial objects (Fribbles).
3. **Prediction:** Examining infants' ability to learn visual patterns, anticipate the location of upcoming stimuli, and update predictions when the location changes.
4. **Audiovisual Synchrony:** Assessing infants' sensitivity to audiovisual alignment by comparing looking time to synchronous and asynchronous speech videos.
5. **Word Comprehension:** Assessing infants' real-time comprehension of familiar words using a looking-while-listening task with named target and distractor images.
6. **Social Evaluation (Helper–Hinderer):** Examining infants' preference for prosocial versus antisocial agents after observing animated helping and hindering events.
7. **Numeracy:** Assessing infants' sensitivity to changes in nonsymbolic numerical quantities by comparing looking time to constant versus alternating streams of dots.

Individual tasks use different stimulus formats and presentation sequences.

# RISE Audio Stimuli (MP3)

This folder contains MP3 audio files used in the **Remote Infant Studies of Early Learning (RISE)** battery.

## Folder structure

```text
mp3/
├── LookitEnd_Sound.mp3
└── sample_1.mp3
```

## File descriptions

- **`LookitEnd_Sound.mp3`**: Audio file to key parents into the end of a task. This is used at the end over every task.
- **`sample_1.mp3`**: Sample audio file.
